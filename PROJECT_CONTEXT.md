Project: Mboa Market
Type: B2B/B2C discovery marketplace in Cameroon (display catalog, not checkout)
Stack: React, Django, PostgreSQL

How it works:
- Vendors display products on Mboa (their public storefront/listings)
- Users browse products
- Users contact vendors by phone number (call / WhatsApp)
- Sale happens off-platform

Core Features:
- Vendors upload/list products for display
- Users browse products
- Users contact vendors via phone (WhatsApp / call)

Future features (post-MVP):
- See docs/future-implementations.md (jobs, events, traditional languages, admin, uploads, map, apps, + suggestions)
- Jobs board: businesses post job openings, seekers search and contact employers by phone/WhatsApp (no in-app applications)
- Shop events & announcements: shops post small events (promo days, new arrivals) on their storefront, display-only
- Traditional languages after EN/FR (Ewondo, Duala, Bamileke, Fulfulde, …)

Rules:
- Mobile-first UI
- Keep MVP simple
- No payments / cart / checkout yet
